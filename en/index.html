Why Zap

  • Made for agents. Fewer tokens per program, errors that say how to fix them.
  • Kernel to script. One language for every layer, nothing to switch to.
  • Safe with no ceremony. Memory is checked at compile time with nothing written for it: no lifetimes, no annotations, no garbage collector.
  • Built for data. Parallel loops, vectors and tensors are the language itself, not C hiding under a wrapper.
  • CPU and GPU alike. A shader is Zap, under the same types and rules; zap-engine is built on it.
  • One tool, no setup. zap builds, runs, tests, formats and documents; the compiler writes executables by itself, with no C compiler or linker.
