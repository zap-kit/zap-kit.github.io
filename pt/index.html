Por que Zap

  • Feito para agentes. Menos tokens por programa e erros que dizem como corrigir.
  • Do kernel ao script. Uma só linguagem para todas as camadas, sem precisar trocar de ferramenta.
  • Seguro sem cerimônia. A memória é verificada em tempo de compilação sem que você escreva nada para isso: sem lifetimes, sem anotações, sem coletor de lixo.
  • CPU e GPU do mesmo jeito. Um shader é Zap, com os mesmos tipos e regras; o zap-engine é construído sobre isso.
  • Uma ferramenta, sem configuração. O zap compila, executa, testa, formata e documenta; o compilador gera os executáveis sozinho, sem compilador C nem linker.

Instalar

Cole isto no seu agente de código (Claude Code, Codex, Cursor):

Instale a linguagem de programação Zap neste Windows a partir de https://github.com/zap-kit/zap: clone o repositório, rode `bootstrap/zap-seed.exe run build.zap` dentro dele para gerar `build/zap.exe`, adicione essa pasta build ao PATH do meu usuário e rode `zap test spec` para conferir que funciona. Antes de escrever código Zap, leia o AGENTS.md do repositório e use `zap doc` para consultar.

Ou à mão:

git clone https://github.com/zap-kit/zap
cd zap
bootstrap/zap-seed.exe run build.zap   # -> build/zap.exe
zap run app.zap                        # compile and run
zap build app.zap                      # build/app.exe
zap test                               # every check
